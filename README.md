# ナゴヤ人間RUN 🏃💨

名古屋の名所を走ってクリアし、豆知識を集めるコース選択型のランアクションゲーム。
**ブラウザだけで遊べます。インストール不要・依存ライブラリゼロ・単一HTMLファイル。**

[![遊ぶ](https://img.shields.io/badge/▶_PLAY-d8372e?style=for-the-badge)](https://241yusei.github.io/nagoya-ningen-run/)

> 「ナゴヤ人間」を操作して、名古屋駅から大須、名古屋城、IGアリーナまで——9つの名所を駆け抜けよう。全部クリアすると、名古屋の主要スポットとその豆知識が自然と頭に入る“遊んで知る”ゲームです。

---

## 🎮 遊び方

| 操作 | キーボード | スマホ |
|---|---|---|
| ジャンプ（長押しで高く／空中でもう一度押すと二段ジャンプ） | `Space` / `↑` | 画面右半分をタップ |
| スライド（くぐる／空中で押すと急降下） | `↓` | 画面左半分をタップ |
| 一時停止 | `P` | 右上のⅡボタン |
| サウンド切替 | `M` | タイトル右上／ポーズ画面 |

- 障害物を**ギリギリで回避すると「PERFECT」**。コンボでスコア倍率が最大×3まで上がります。
- 穴（ピット）に落ちると一発アウト。HPは難易度で変化（かんたん3／ふつう2／むずかしい1）。
- 名物アイテムを3つ全部集めるとクリアボーナス。

## 🗺 コース（全9＋隠し要素）

名古屋駅 → 大須商店街 → 久屋大通パーク → オアシス21 → 名古屋城 → 熱田神宮 → 名古屋港水族館 → 東山動植物園 → IGアリーナ

各コースに固有のメカニクス（精密ジャンプ／スライド／二段ジャンプ＋足場／コイン回収／ピット越え／リズムジャンプ／波乗り／動く障害物／総合）と、**事実に基づく豆知識カード**を用意。全コース全難易度を制覇すると隠しキャラ「金シャチ人間」が解放されます。

## 🕹 起動方法

- **オンライン**: 上の PLAY ボタン（GitHub Pages）
- **ローカル**: このリポジトリをダウンロードし、`index.html` をブラウザで開くだけ
  （`sprites/` フォルダと画像ファイルは同じ場所に置いてください）

## 🛠 技術

- HTML5 Canvas + 素のJavaScript、**依存ライブラリなし**
- 物理は固定120Hzタイムステップ（端末のリフレッシュレートに依存しない挙動）
- キャラクターは3Dレンダー立ち絵をパーツ分割し、関節アニメーションで走らせるカットアウト方式
- 背景・障害物はすべてCanvasによるオリジナルのコード作画
- BGM／効果音はWeb Audio APIでリアルタイム合成（音声ファイル不使用）
- 進捗（クリア状況・ハイスコア・解放要素）は `localStorage` に保存

設計の詳細は [DESIGN.md](DESIGN.md) を参照。

## ℹ️ 豆知識・固有名詞について

ゲーム内の豆知識は2026年6月時点の情報をもとにしています。実在の施設名・固有名詞は事実の紹介（豆知識）として言及しているもので、各施設・企業とは関係ありません。背景はすべてオリジナルのデフォルメ表現であり、実在のロゴ・写真は使用していません。進行中の事案（名古屋城天守の木造復元、名駅再開発など）は今後変わる可能性があります。
