# 家系図 — Kinship

入力した情報から、**バランスのよい家系図を自動でつくる**シングルページの Web アプリです。
インストール不要・依存ライブラリゼロ・単一 HTML ファイルで動きます。

👉 公開URL: `https://241yusei.github.io/<リポジトリ名>/family-tree/`
（GitHub Pages はリポジトリ名が URL に入ります。例：リポジトリ名が `kakeizu` なら `https://241yusei.github.io/kakeizu/family-tree/`）

## できること

- **名前を入れていくだけ**で、世代ごとにきれいに整列した家系図が自動生成されます。
- **配偶者・子ども・親・きょうだい**を、各カードのボタンからどんどん追加できます。
- **姓（名字）が違っても、血のつながりがあれば記録**できます。結婚で姓が変わった方、再婚、養子など、いろいろな家族の形をそのまま残せます。
- 名前を**タップ／クリック**すると、生年月日・没年月日（入力した場合のみ）・年齢・享年・続柄・メモが表示されます。
- 新しく追加したときは、**カードがふわっと現れて金色の光が舞う演出**が入ります。
- 図は指やマウスで**つかんで移動**、ピンチ／ホイール／＋－ボタンで**拡大縮小**、⤢ボタンで**全体表示**。
- データはこの端末（ブラウザ）に**自動保存**。書き出し（バックアップ）・読み込みもできます。
- **60代の方でも迷わない**よう、「使い方ガイド」を常設しています。

## 取り入れている家系図の情報

姓・名・よみがな・性別・生年月日・没年月日・存命/故人・メモ（旧姓・出身地・職業など）、
そして 親子・配偶者・きょうだい の関係。

## レイアウトの仕組み

- 親子関係から各人物の**世代（縦位置）**を決定。
- 夫婦は隣り合わせの「ユニット」として配置し、子どもはその中央の下にぶら下げます。
- 子の集まりの中央に親が来るよう、衝突回避とセンタリングを数回くり返して**左右バランス**を整えます。
- 横線＝婚姻、縦線＝血のつながり、として描き分けています。

## 技術

- HTML + 素の JavaScript + SVG。**依存ライブラリなし**。
- 表示は HTML カード（文字がきれい）＋ SVG の接続線のレイヤー構成。
- 文字は Noto Serif JP / Noto Sans JP（読み込めない環境ではシステムフォントにフォールバック）。
- 保存は `localStorage`。
